{% comment %} Edit mode: "+ add" for a relation - a picker (cmnsd.js picker.js) that links the chosen object (EditableRelationsMixin link) and appends the returned chip to `target`. With `can_create`, a search without an exact match offers to create it by name (the relation's `create` config; the server checks the add permission again). Context: model, owner, relation, picker_model (the related model's API name), target (CSS selector of the chip list), label, placeholder, can_create, exclude (comma-separated tokens already linked), search_character. Optional, for a related model that's created elsewhere (more fields than a name): new_url + new_param + new_label + can_new - without an exact match the picker offers a link to new_url with ?=, in a new tab. Or `new_dialog` (a cmnsd object_create URL, api//new/) instead of new_url: the form opens in a dialog and what's made is chosen right away (cmnsd.js dialog.js). Optional `action` (default link) and `insert` (default append): another action taking {relation, token} - e.g. a person's add_relative, with insert='reload' when the change reaches further than one chip. {% endcomment %}
